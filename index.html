UniVerseTEAM LEADER · A+ (9.0/10)

A smart university system for students, lecturers, and administrators. It replaces scattered websites, hand-taken attendance that is easy to fake, and late announcements. Foundation Practicum (TTCS), PTIT, team HTH of 3.

  • JavaFX desktop app for admins and lecturers, Android app for students with QR code and GPS attendance.
  • Java REST API on Render, PostgreSQL (12 tables), Redis for sessions, Kafka for notifications.
  • 10 core functions built in three iterations, each with use case scenarios, class and sequence diagrams, and black-box test cases.
  • My part: led the team, wrote the requirements chapter, drew the shared class and entity relationship diagrams, and built three modules end to end (edit user information, send notifications to students, edit class schedules).
  • We listed our own weak points: shared QR photos, fake GPS, and no load balancing. Face recognition, a dynamic QR code, and a web portal are the next steps.
